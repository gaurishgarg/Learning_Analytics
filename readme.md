# Learning Analytics: Gaze and Interaction Analysis

This repository contains the notebooks used to analyze learner gaze and interaction data for three research questions (RQs).


## Getting Started

Before running the notebooks, download the dataset and the LA-CaRM TNA
notebook.

### 1. Download the Dataset

Download the [A Robot Story dataset](https://drive.google.com/drive/folders/1U6oMZnut2iUSVVAC1cIOb6B9X2iFc2Lw).

From the downloaded dataset:

- Locate `robotcomprehension.xlsx`.
- Save/export this file as `robo.csv`.

### 2. Download the Repository

Download or clone this repository and place the downloaded dataset root folder in the
repository root folder.

The folder structure should be similar to:

```text
Learning_Analytics/
├── README.md
├── robo.csv
├── gaze_Data_aoi_sequence_one.ipynb
├── interaction_data_one.ipynb
├── aggregation_rq1and2.ipynb
├── preparation_for_rq3.ipynb
├── tna.ipynb
└── ...
```

The code files and dataset should be located in the same root folder so that
the notebooks can access the required input files.

### 3. Download LA-CaRM TNA

Download [CarmNote-TNA v2.3.86](https://github.com/mohsaqr/CarmNote-TNA/releases/download/tna-v2.3.86/tna-notebook_V2.3.86-full-j.html).

LA-CaRM is used for sequential pattern mining and transition-weight calculation in the RQ3 analysis. The transition-weight CSV files generated by LA-CaRM are subsequently used in `tna.ipynb`.

### 4. Run the Notebooks

Run the notebooks sequentially as described in the
[Analysis Pipeline Overview](#-analysis-pipeline-overview):

1. `gaze_Data_aoi_sequence_one.ipynb`

2. `interaction_data_one.ipynb`

3. `aggregation_rq1and2.ipynb`

4. `preparation_for_rq3.ipynb`

5. `verify.ipynb`

6. `tna.ipynb`


## 🛠️ Analysis Pipeline Overview

The notebooks must be run in the following sequential order:

1. `gaze_Data_aoi_sequence_one.ipynb`
2. `interaction_data_one.ipynb`
3. `aggregation_rq1and2.ipynb`
4. `preparation_for_rq3.ipynb`
5. `tna.ipynb`

---

## Pipeline Stages

### 1. Gaze Data and Gaze Episodes

* **Notebook:** `gaze_Data_aoi_sequence_one.ipynb`
* **Description:** Processes raw gaze observations and constructs continuous gaze episodes.

#### Main Steps
- Read gaze CSV and JSON files across all users.
- Combine gaze data into a single unified dataset.
- Identify valid gaze observations.
- Map gaze observations to specific learning elements using interaction data.
- Order observations chronologically per learner.
- Group continuous AOI runs into distinct gaze episodes.
- Calculate episode-level metrics:
  - `gaze_start`
  - `gaze_end`
  - `gaze_count`
  - `gaze_duration_seconds`

#### Outputs
- `aoi_sequence_final.csv`
- `gaze_episodes_final.csv` *(Used in RQ1, RQ2, and RQ3 data preparation)*

---

### 2. Interaction Data Cleaning

* **Notebook:** `interaction_data_one.ipynb`
* **Description:** Prepares interaction events for subsequent analysis.

#### Main Steps
- Read raw interaction data (`robo.csv`).
- Map interaction events to learning elements.
- Remove interactions lacking an associated learning element.

#### Output
- `interaction_clean_final.csv` *(Used in RQ3 data preparation)*

---

### 3. RQ1: Gaze Analysis and Clustering

* **Notebook:** `aggregation_rq1and2.ipynb`
* **Description:** Aggregates gaze episodes to calculate element-level metrics and performs K-Means clustering.

#### Inputs
- `aoi_sequence_final.csv`
- `gaze_episodes_final.csv`

#### Analysis Breakdown
* **RQ1 (Descriptive Analysis):** Gaze episodes are aggregated across learners to compute:
  - Average total gaze duration per learning element from `gaze_episodes_final.csv`
  - Average gaze episode count per learning element from `gaze_episodes_final.csv`
  - Switches per element from `aoi_sequence_final.csv` but not used to high correlation
* **RQ1 (Clustering):** K-Means clustering is performed using:
  - `avg_gaze_duration`
  - `avg_episode_count`
  - *Result:* Grouping learning elements into **three distinct gaze-behavior clusters**.

#### Output
- `clustered_element_analysis.csv` *(Contains learning elements, gaze metrics, and assigned cluster labels)*

---

### 4. RQ2: Data Preparation for Sequential Analysis

* **Notebook:** `preparation_for_rq3.ipynb`
* **Description:** Maps clusters to gaze and interaction events to prepare input sequences for sequential pattern mining and Transition Network Analysis (TNA).

#### Inputs
- `interaction_clean_final.csv`
- `gaze_episodes_final.csv`
- `clustered_element_analysis.csv`

#### Main Steps
- Map each gaze episode and interaction event to the K-Means cluster of its corresponding learning element.
- Filter out gaze episodes shorter than 0.1 seconds.
- Order events chronologically for each learner.

#### Outputs
- `gaze_interaction_for_spm.csv`
- `interaction_for_spm.csv`

---
---
### 5. Verification and Manual Group Preparation

- **Notebook:** `verify.ipynb`

- **Description:** Verifies the prepared sequence data and creates the manual/predefined cluster mapping for comparison with the K-Means clusters.

#### Inputs

- `gaze_interaction_for_spm.csv`
- `interaction_for_spm.csv`
- `clustered_element_analysis.csv`

#### Main Steps

- Verify the prepared gaze and interaction sequences.
- Check cluster mappings and event ordering.
- Create the manual/predefined cluster grouping.
- Save the manually grouped interaction sequence for LA-CaRM.

#### Output

- `interaction_spm_manual_groups.csv`

---
### 6. LA-CaRM and Transition Weights

- **Tool:** LA-CaRM (External Processing)

- **Description:** LA-CaRM processes the prepared sequences to mine transitions and compute transition weights.

- **Feature Used:**

  - `interaction_cluster_activity`: Used for the combined gaze and interaction analysis.

- **Transition-Weight CSV Outputs:**

  - `weights_total.csv` (Combined gaze and interaction data)

  - `manual_matrix.csv` (Manual/predefined cluster grouping)

- **Manual Cluster Analysis:**

  - `interaction_spm_manual_groups.csv`: Manual/predefined cluster grouping created in `verify.ipynb` and uploaded to LA-CaRM.

  - `manual_matrix.csv`: Transition-weight matrix downloaded from LA-CaRM using the manual grouping.
---
### 7. TNA Visualization

- **Notebook:** `tna.ipynb`

- **Description:** Reads the transition-weight CSV files and renders transition-weight heatmaps and comparisons between K-Means and manual/predefined clusters.

- **Inputs:**

  - `weights_total.csv`
  - `manual_matrix.csv`

- **Output:**

  - **Transition Network Heatmaps:** Display transition strengths and weights between the three K-Means clusters.

  - **K-Means vs Manual Comparison:** Compare inter-cluster transition weights between the K-Means and manual/predefined clusterings.

> **Note:** The CSV files for gaze-only and non-gaze interaction analyses were initially generated and used during development, which is why references to them may still appear in some code. They are not part of the final analysis workflow and can be ignored if they are produced by the code.
